# BLOC_Project — STM32G431 无刷电机驱动项目

> **STM32G431 为核心的 BLDC / PMSM / DC 电机驱动方案**：双闭环（电流环 + 速度环）FOC 控制，支持有感（霍尔）与无感运行，集成多种调速方式，代码由 MATLAB Simulink 生成模型 + 手写 HAL 驱动组成。

## 功能特点

- ⚙️ 支持 **BLDC / PMSM / DC** 三种电机类型
- 🧭 支持 **有感（霍尔六步换向）与无感** FOC 控制
- 🎯 **电流环 + 速度环**双闭环，闭环启动采用零误差切换 + 速度斜坡，稳定可靠
- 🎛️ 四种调速方式：**串口上位机**（参数配置）、**CAN 上位机**（调速）、**电位器**、**旋转编码器**
- 🔌 基于 STM32CubeMX 生成工程（HAL 库），MDK-ARM / IAR 均可编译
- 📚 `docs/` 内含完整学习笔记：FOC 入门到入土、项目完结文档（含调试踩坑总结）

## 硬件组成

| 模块 | 说明 |
|------|------|
| 主控 | STM32G431CBT6（TIM1 六路互补 PWM 输出） |
| 功率驱动 | FD6288T 三相半桥栅极驱动 + 6 × BSC0702LS MOS |
| 电流采样 | 5mΩ 采样电阻 + 运放（11k/1.5k ≈ 7.33 倍） |
| 母线电压 | 75k/3k 分压 + ADC 采样 |
| 通讯 | FDCAN（PA13/PA14）、USART3（PB10/PB11） |
| 反馈 | 霍尔传感器（TIM4 捕获测速） |

## 项目结构

```
Core/        HAL 库初始化代码（ADC/DMA/FDCAN/TIM/USART）
Matlab/      Simulink 生成的 FOC 模型（电流环+速度环 PI 控制）
user/        手写驱动（mycan / myuart 等）
docs/        FOC 学习笔记 + 项目完结文档
MDK-ARM/     Keil 工程
```

## 调试经验（docs/ 有详细记录）

- 霍尔信号 5 项修复：无效跳变过滤、角度同步快照、变量初始化等
- 速度环闭环关键：**零误差启动 + 速度斜坡 + 清空 PI 积分器**（详见 docs/BLDC项目完结文档.md）

## 快速开始

1. 用 Keil 打开 `MDK-ARM/BLOC_Project.uvprojx`
2. 编译烧录到 STM32G431 主控板
3. 上电后 VF 开环拖动 1 秒 → 自动切换有感 FOC 闭环
4. 通过串口 / CAN / 电位器 / 编码器调节目标转速
