# BLDC 项目完结文档

> STM32G431 + FD6288T 驱动板 — 有感/无感 FOC 驱动器

---

## 一、项目概述

本项目基于 STM32G431CBT6 微控制器，配合 FD6288T 三相栅极驱动芯片，实现了一台无刷直流电机（BLDC）的磁场定向控制（FOC）驱动器。项目使用 Simulink 自动生成的 FOC 算法代码，支持有霍尔传感器和无传感器两种控制模式，支持串口、CAN、电位器三种调速方式。

### 硬件架构

```
24V DC ──┬──→ SCT2A10STER ──→ 12V ──→ SCT2230TVBR ──→ 5V ──→ AMS1117 ──→ 3.3V
          └──→ 三相逆变桥 (BSC0702LS × 6) ──→ 电机三相绕组
                      ↑
              FD6288T 栅极驱动
                      ↑
              STM32G431 输出 6 路互补 PWM
```

### 软件架构

```
ADC 中断 (10kHz) ──→ 读电流 → FOC_Model_step() → 写 CCR
       ↑                         ↑
TIM1_CH4 触发               FOC_Model 内部
                            ├─ 状态机 (IDLE→Align→Open→Theta→Run)
                            ├─ 电流环 (10kHz)
                            ├─ 速度环 (1kHz)  
                            ├─ 磁链观测器 + PLL (无感用)
                            └─ SVPWM 输出

TIM4 中断 (霍尔边沿) ──→ 更新角度和速度

main 循环 ──→ FDCAN_Control() → CAN 调速
           → USART3_Anylze() → 串口调参
           → send_UVWV() → VOFA 数据上报
```

## 二、项目功能介绍

### 2.1 有感 FOC 控制（霍尔传感器）

**原理：** 三个霍尔传感器（120° 间隔）安装在电机内部，检测转子磁极位置。每当转子转过 60° 电角度，三个霍尔的电平组合变化一次，共 6 种有效状态（格雷码编码）。

**霍尔信号采集：** TIM4 配置为霍尔传感器模式，三路霍尔信号（PB6/PB7/PB8）的任意一路电平跳变都会触发 TIM4 输入捕获中断。在中断服务函数中读取捕获值并更新转子角度和转速。

**关键函数：**

| 函数 | 位置 | 作用 |
|:----|:----|:-----|
| `HALL_Init_Electrical_Angle()` | Hall_driev.c | 上电时读取初始霍尔状态，确定转子所在扇区 |
| `HALL_Get_Electrical_Angle()` | Hall_driev.c | 霍尔边沿触发时调用，解码状态跳变、计算电角度基准、计算速度 |
| `HAL_TIM_IC_CaptureCallback()` | stm32g4xx_it.c | TIM4 输入捕获中断回调，调用 HALL_Get_Electrical_Angle |

**角度插值：** 霍尔传感器每 60° 电角度才更新一次位置。为了获得连续平滑的角度，在 ADC 回调中（每 100μs）用 `AvrElSpeedDpp`（每步的电角度增量）累加角度，在两个霍尔边沿之间做线性插值。

**5 项霍尔信号修复（调试经验）：**

| 修复 | 解决什么问题 |
|:----|:------------|
| `bValidTransition` 标志 | 霍尔噪声导致的虚假触发会计算出巨大速度，跳过无效跳变 |
| 初始化所有变量 | 复位后 RAM 值不确定，导致速度环初始状态异常 |
| 每个 case 设置 bValidTransition | 只对有效霍尔跳变计算速度和角度 |
| switch 后跳过无效跳变 | 防止无效跳变污染速度 LPF 滤波结果 |
| 先保存 bHallUpdated 再清零 | 保证角度同步和速度反馈都能读到正确的霍尔数据 |

### 2.2 无感 FOC 控制（磁链观测器 + PLL）

**原理：** 电机旋转时，转子永磁体在定子绕组中产生反电动势（Back-EMF）。反电动势的相位包含转子位置信息。通过观测反电动势，就能估算出转子角度，无需霍尔传感器。

**FOC_Model 中的磁链观测器结构：**

```
FluxObserver (磁链观测器) → LPF (低通滤波) → PLL (锁相环) → FluxTheta (估算角度)
                                                             → FluxWe (估算速度)
```

| 模块 | Simulink 路径 | 作用 |
|:----|:-------------|:-----|
| FluxObserver | `<S16>` | 根据电流和电压估算定子磁链 |
| LPF | `<S17>` | 低通滤波，滤除观测器噪声 |
| PLL | `<S18>` | 锁相环跟踪磁链角度，输出平滑的 θ 和 ω |

**有/无感切换：** 通过全局变量 `Hal_State` 控制：

```c
if (Hal_State == 0)     // 无感模式
    theta = FluxTheta;   // 使用磁链观测器估算角度
else                     // 有感模式
    theta = HALL_Handle.MeasuredElAngle;  // 使用霍尔传感器角度
```

**启动流程（FOC_Model 内置状态机）：**

| 状态 | 持续时间 | 行为 |
|:----|:--------:|:-----|
| IDLE (state=1) | — | 等待 `Motor_OnOff=1` |
| AlignStage (state=2) | 100ms | 固定角度注入 Iq，将转子拉到已知位置 |
| OpenStage (state=3) | 3s | 开环拖动，频率从 0 开始斜坡上升 |
| ThetaAlign (state=4) | 500ms | 观测器角度和开环角度对齐过渡 |
| RunStage (state=5) | — | 闭环运行，速度和电流双环控制 |

**状态机代码（FOC_Model.c 中 Switch Case 结构）：**

```c
switch ((int32_T)state) {
    case 1:  /* IDLE：输出 0 角度 + 0 Iq */
        rtDW.Merge = 0.0F;      // theta_fd = 0
        rtDW.Merge1 = 0.0F;     // iq_ref = 0
        break;

    case 2:  /* AlignStage：定位 */
        /* 固定角度 + Iq=1.0 */
        rtDW.Merge1 = 1.0F;
        break;

    case 3:  /* OpenStage：VF 开环拖动 */
        /* 两个离散积分器：一个积分频率斜坡，一个积分角度 */
        /* 角度 = mod(∫(Pn × 2π × 0.333 × Freq), 2π) */
        rtDW.Merge = rt_modf_snf(DiscreteTimeIntegrator1_a, 6.28318548F);
        rtDW.Merge1 = 1.0F;     // iq_ref = 1.0
        break;

    case 4:  /* ThetaAlign：角度对齐过渡 */
        /* 过渡系数 ramp 每周期 +0.01（→1.0 需要 100 个周期 = 10ms） */
        if (rtDW.UnitDelay_DSTATE_h + 0.01F >= 1.0F)
            rtb_SignPreIntegrator_b = 1.0F;      // 到顶保持
        else
            rtb_SignPreIntegrator_b = rtDW.UnitDelay_DSTATE_h + 0.01F;
        /* iq_ref 从 1.0 渐降到 0.8：Merge1 = 1 - ramp × 0.2 */
        rtDW.Merge1 = 1.0F - rtb_SignPreIntegrator_b * 0.2F;
        break;

    case 5:  /* RunStage：闭环（速度环 + 电流环 + 观测器） */
        break;
}
```

**关键理解（面试讲）：**
- **OpenStage 的 iq_ref=1.0**：开环拖动时给恒定 Iq（恒定力矩），速度由角度积分器（频率斜坡）决定——这就是"VF 开环"的本质：给电压/电流，不反馈速度
- **ThetaAlign 的过渡**：`1 - ramp×0.2` 让 Iq 从开环的 1.0 渐变到闭环的值，**防止切闭环瞬间电流突变**（相当于"软切入"）
- 切到 RunStage 时角度已经对齐（ThetaAlign 期间角度连续过渡），所以不会跳变

### 2.3 FOC 算法（Simulink 自动生成）

**FOC 控制链路：**

```
ia, ib, ic (三相电流)
    ↓
Clark 变换 → Iα, Iβ (两相静止坐标系)
    ↓
Park 变换 → Id, Iq (两相旋转坐标系)，需要 θ 角
    ↓
Id PI 控制器 → Ud        Iq PI 控制器 → Uq
    ↓
逆 Park 变换 → Uα, Uβ (需要 θ 角)
    ↓
SVPWM → tABC (三相占空比) → TIM1->CCR1/2/3
```

**电流环（内环）：** 运行频率 10kHz。控制 Id=0（不产生励磁），控制 Iq 产生扭矩。PI 参数：

```
CurrKp = 0.017    CurrKi = 35.0
```

**速度环（外环）：** 运行频率 1kHz（每 10 次电流环执行一次）。PI 输出作为 Iq 参考值输入电流环：

```
spd_kp = 0.003389    spd_ki = 0.000144
```

**SVPWM（空间矢量调制）：** 将 Uα, Uβ 合成为三相马鞍波，相比正弦波调制，母线电压利用率提高约 15%。

### 2.4 PWM 生成

**TIM1 配置：**

| 参数 | 值 |
|:----|:---:|
| 预分频 | 0 (170MHz) |
| 计数模式 | 中央对齐 (Center-aligned) |
| ARR | 8500 |
| 死区时间 | 120 个时钟周期 (~0.7μs) |
| PWM 频率 | 170MHz ÷ (2 × 8500) ≈ 10kHz |

**引脚映射：**

| TIM1 通道 | GPIO | 驱动板 | 相序 |
|:---------|:----|:-------|:----:|
| CH1 + CH1N | PA8 + PB13 | HIN3 + LIN3 | W 相 |
| CH2 + CH2N | PA9 + PB14 | HIN2 + LIN2 | V 相 |
| CH3 + CH3N | PA10 + PB15 | HIN1 + LIN1 | U 相 |
| CH4 | PA11 | ADC 触发 | — |

FOC 算法计算出的 tABC 值写入 TIM1->CCR1/2/3，硬件自动比较计数器值，输出对应占空比的 PWM 波形。

### 2.5 电流采样

**三电阻采样方案：** 三个采样电阻（各 5mΩ）串联在三相下桥 MOS 管的源极和 GND 之间，通过 STM32G431 内置运放（OPAMP）放大后由 ADC 采集。

**运放增益：** 7.33 倍（11kΩ ÷ 1.5kΩ），1.65V 共模偏置。

**触发方式：** TIM1_CH4 的 OC4REF 信号触发 ADC1 和 ADC2 的注入组同步转换（与 PWM 同步，避开开关噪声）。

**ADC 通道：**

| ADC | 通道 | 引脚 | 信号 | 寄存器 |
|:---|:----|:----|:----|:------|
| ADC1 | IN3 | PA2 | U 相电流 | JDR1 |
| ADC1 | IN12 | PB1 | V 相电流 | JDR2 |
| ADC1 | IN1 | PA0 | 母线电压 | JDR3 |
| ADC2 | IN3 | PA6 | W 相电流 | JDR1 |

**偏移校准：** 上电后前 10 次采样不做控制，只采样并累加零漂值。之后每次采样减去零漂，得到真实电流值。

**ADC 中断回调（核心，100μs 一次）：**

```c
void HAL_ADCEx_InjectedConvCpltCallback(ADC_HandleTypeDef *hadc)
{
    UNUSED(hadc);
    if(hadc->Instance == ADC1)
    {
        if(ADC_OffSet == 0)
        {
            /* 偏移校准阶段：前 10 次只累加零漂 */
            cnt++;
            offset[0] += ADC1->JDR1;   // U 相电流原始值
            offset[1] += ADC2->JDR1;   // W 相电流原始值
            offset[2] += ADC1->JDR2;   // V 相电流原始值
            if(cnt >= 10) {
                offset[0] /= 10.0f;    // 求平均零漂
                offset[1] /= 10.0f;
                offset[2] /= 10.0f;
                ADC_OffSet = 1;        // 校准完成，开始控制
            }
        }
        else
        {
            hall_FOC_mode();           // 每 100μs 执行一次 FOC
        }
    }
}
```

**FOC 执行（hall_FOC_mode 关键结构）：**

```c
void hall_FOC_mode(void)
{
    /* 1. 读电流（原始 ADC 值 - 零漂）× 电流系数 */
    CurrlValue[0] = (ADC1->JDR1 - offset[0]) * 0.02197f;   // U 相
    CurrlValue[1] = (ADC2->JDR1 - offset[1]) * 0.02197f;   // W 相
    CurrlValue[2] = (ADC1->JDR2 - offset[2]) * 0.02197f;   // V 相

    /* 2. 有感模式：角度插值（每周期累加速度增量） */
    if (Hal_State == 1) {
        HALL_Handle.MeasuredElAngle += HALL_Handle.AvrElSpeedDpp;
        HALL_Handle.HallElAngle += HALL_Handle.AvrElSpeedDpp + HALL_Handle.DeltaAngle;
        /* 归一化到 [0, 2π) */
        if (HALL_Handle.HallElAngle < 0.0f) HALL_Handle.HallElAngle += 2.0f * PI;
        else if (HALL_Handle.HallElAngle > 2.0f * PI) HALL_Handle.HallElAngle -= 2.0f * PI;
    }

    /* 3. 填模型输入，执行一步 FOC（状态机 + 电流环 + 速度环 + 观测器） */
    rtU.ia = CurrlValue[0];
    rtU.ib = CurrlValue[1];
    rtU.ic = CurrlValue[2];
    rtU.v_bus = ADC1->JDR3 * 0.020947f;   // 母线电压（分压 1/26）
    rtU.Motor_OnOff = 1.0f;
    FOC_Model_step();

    /* 4. 写 PWM 占空比 */
    TIM1->CCR1 = (uint32_t)rtY.Tcmp1;
    TIM1->CCR2 = (uint32_t)rtY.Tcmp2;
    TIM1->CCR3 = (uint32_t)rtY.Tcmp3;
}
```

**关键理解（面试讲）：**
- **电流系数 0.02197**：ADC 值 → 电流的换算（含运放增益 7.33、采样电阻 5mΩ、ADC 参考电压 3.3V、12bit 分辨率 4096）
- **为什么在 ADC 中断里执行 FOC**：电流环必须和 PWM 同步且实时，中断里执行保证 10kHz 恒定周期
- **为什么用 JDR 寄存器**：注入组转换结果存 JDR（JDR1~JDR3），普通规则组存 DR——注入组由 TIM1_CH4 硬件触发，时序精确

### 2.6 速度闭环

**速度环在 FOC_Model 内部自动运行（1kHz），不需要手动干预。**

**速度环链路：**

```
SpeedRef（外部输入：串口/CAN/电位器）
    ↓
误差 = SpeedRef - FluxWe（磁链观测器 PLL 输出的估算速度）
    ↓
速度环 PI（spd_kp=0.003389, spd_ki=0.000144）
    ↓
输出限幅 → 作为 Iq 参考 → 电流环
```

**速度反馈来源：** 无论有感还是无感模式，速度反馈始终来自 `FluxWe`。有感时霍尔角度只覆盖模型内部的 theta 角度用于 Park/反 Park 变换，不影响速度反馈。

**启动过程由 FOC_Model 内部状态机自动管理：**

| 阶段 | 时长 | 行为 |
|:----|:----:|:-----|
| AlignStage | 100ms | 固定角度注入 Iq，转子定位 |
| OpenStage | 3s | VF 开环拖动，内部自动做频率斜坡和角度积分 |
| ThetaAlign | 500ms | 开环角度和估算角度对齐，保证切到闭环时角度连续 |
| RunStage | — | 闭环运行，速度环和电流环正常工作 |

模型内部在 ThetaAlign 阶段已经做了角度同步和速度缓冲，切到 RunStage 时不会出现速度跳变。**不需要手动做零误差启动、速度斜坡或清积分器。**

> **历史背景：** 早期手动 VF→FOC 切换方案中，切闭环瞬间 SpeedRef 和实际转速相差太大会导致 PI 饱和无法闭环。当时的修复方案是零误差启动 + 速度斜坡 + 清积分器。切换到 FOC_Model 后该问题由模型内部自动处理，不再需要手动维护。

### 2.7 VF 开环控制（备用启动方式）

VF 模式不依赖任何位置反馈，直接给电机施加旋转电压，电机被电压产生的旋转磁场拖动着转。用于电机参数测试和低转速启动场景。

```c
VF_rtU.ud   = 0.0f;       // 直轴电压
VF_rtU.uq   = 12.0f;      // 交轴电压（产生扭矩）
VF_rtU.Freq = 4.0f;       // 电频率 4Hz
```

### 2.8 串口上位机通信

**协议格式（VOFA+ JustFloat 协议）：**

```
帧头 0xAA 0x55 | 指令码 | 4 字节数据 (float, 小端) | 帧尾 0x55 0xAA
```

**支持的命令：**

| 指令码 | 功能 | 数据 |
|:-----:|:----|:----|
| 0x01 | 电机启停 | 无 |
| 0x02 | 速度设定 | float RPM |
| 0x03 | 速度环 Kp | float |
| 0x04 | 速度环 Ki | float |
| 0x05 | 电流环 Kp | float |
| 0x06 | 电流环 Ki | float |
| 0x0C | 有感/无感切换 | float: 0=无感 1=有感 |

**实现要点：**
- 使用 DMA + IDLE 中断实现不定长帧接收
- RX DMA 工作在 Circular 模式，帧尾空闲时触发中断
- 每次解析完重新启动 DMA 接收

### 2.9 CAN 上位机调速

**帧格式（标准帧，ID=0x125，8 字节）：**

| 字节 | 含义 |
|:---:|:----|
| [0] | 0x01=启动，其他=停止 |
| [1] | 0x01=正转，其他=反转 |
| [2] | 速度高 8 位 |
| [3] | 速度低 8 位 |

**关键函数：** `FDCAN_Control()` 在 `mycan.c` 中，在 main 循环中轮询调用。检查到新帧后解析数据，更新 `rtU.SpeedRef` 和 `rtU.Motor_OnOff`。

**配置：**
- 经典 CAN 模式，**531.25kHz**（FDCAN 时钟 170MHz ÷ 预分频 20 ÷ (1+10+5) = 531.25kHz）
- 滤波器设为范围过滤，接收 ID 0x000~0x1FF
- 接收 FIFO 中断触发，置位新帧标志后由主循环处理

### 2.10 电位器调速

电位器接 PB12（ADC1_IN11），10 次采样取平均值消除抖动，映射到 600~2300 RPM 的范围。

```c
if (电位器电压 > 1.65V)
    SpeedRef = (电压差值 × 0.83) + 600    // 正转
else
    SpeedRef = -((1.65V - 电压) × 0.83 + 600)  // 反转
```

## 三、关键算法解析

### 3.1 Clark 变换

将三相电流 ia, ib, ic 变换到两相静止坐标系 Iα, Iβ：

```
Iα = 2/3 × ia - 1/3 × (ib + ic)
Iβ = (ib - ic) / √3
```

由于 ia + ib + ic = 0（星形连接，无中性线），可简化为：

```
Iα = ia
Iβ = (ib - ic) / √3
```

### 3.2 Park 变换

将两相静止坐标系 Iα, Iβ 变换到两相旋转坐标系 Id, Iq（随转子同步旋转）：

```
Id  =  Iα × cosθ + Iβ × sinθ
Iq  = -Iα × sinθ + Iβ × cosθ
```

- Id 是励磁分量（产生磁场），控制目标为 0
- Iq 是转矩分量（产生力矩），由速度环输出决定

### 3.3 逆 Park 变换

将 Ud, Uq 变换回 Uα, Uβ：

```
Uα = Ud × cosθ - Uq × sinθ
Uβ = Ud × sinθ + Uq × cosθ
```

### 3.4 SVPWM（空间矢量调制）

将 Uα, Uβ 合成为三相马鞍波，比 SPWM 母线电压利用率高约 15%。

```
1. 逆 Clark：Ua = Uα, Ub = -0.5×Uα+√3/2×Uβ, Uc = -0.5×Uα-√3/2×Uβ
2. 零序注入：V0 = -0.5×(Umax + Umin)
3. 调制：tABC = (-(Ux + V0) / Vbus + 0.5) × 8500
```

### 3.5 磁链观测器（无感核心）

根据电机电压方程，从静止坐标系下的电压和电流估算定子磁链：

```
ψα = ∫(uα - Rs × iα) dt
ψβ = ∫(uβ - Rs × iβ) dt
```

从磁链中提取反电动势：

```
eα = dψα/dt - L × diα/dt
eβ = dψβ/dt - L × diβ/dt
```

### 3.6 PLL（锁相环）

从估算的反电动势中提取角度和速度。PLL 相比直接 atan2 计算的优势：输出平滑、抗噪声、天然带滤波。

```
误差 = êα × cosθ̂ + êβ × sinθ̂ (当 θ̂ 接近 θ 时，误差 ≈ θ - θ̂)
↓
PI 控制器 → ω̂ (估算速度)
↓
积分器 → θ̂ (估算角度)
```

### 3.7 霍尔传感器驱动

```c
// 霍尔状态解码（正转：1→5→4→6→2→3→1）
switch (HallState) {
    case 5:  // 101: 正转从 1 来，反转从 4 来
    case 4:  // 100: 正转从 5 来，反转从 6 来
    case 6:  // 110: 正转从 4 来，反转从 2 来
    case 2:  // 010: 正转从 6 来，反转从 3 来
    case 3:  // 011: 正转从 2 来，反转从 1 来
    case 1:  // 001: 正转从 3 来，反转从 5 来
}
```

> **注意区分两种霍尔表**：
> - 本表是 **FOC 电角度基准表**（角度级）：每个霍尔状态对应一个 60° 扇区的电角度基准，用于 Park/逆 Park 变换的角度
> - 另外有一种**六步方波换向表**（功率级）：每个状态对应"哪两个 MOS 管导通"，用于方波控制（BLDC 六步换相）
> - 两者用途不同、状态编号的 bit 顺序也可能不同，**不要混用**。本项目是 FOC（SVPWM），只用上面的角度基准表。

速度计算：

```
AvrElSpeedDpp = (π/3) / (TIM4 捕获值 / 3.2M × 10000)
TempSpeed = (π/3) / (TIM4 捕获值 / 3.2M) × 30 / (2π)
HallSpeed = LPF(HallSpeed, TempSpeed × Direction, 0.2379)
```

#### 附：六步方波换向真值表（参考，方波控制用）

> 本项目用 FOC 不需要这个表，但了解它有助于理解"为什么 FOC 比方波好"。**正转与反转的 MOS 管开关正好镜像对称，同一时刻 2 个 MOS 管导通（一上一下），第三相悬空。**

**正转（↑）：**

| 霍尔W | 霍尔V | 霍尔U | U+ | U- | V+ | V- | W+ | W- |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 1 | 0 | 1 | 开 | 关 | 关 | 开 | 关 | 关 |
| 0 | 0 | 1 | 开 | 关 | 关 | 关 | 关 | 开 |
| 0 | 1 | 1 | 关 | 关 | 开 | 关 | 关 | 开 |
| 0 | 1 | 0 | 关 | 开 | 开 | 关 | 关 | 关 |
| 1 | 1 | 0 | 关 | 开 | 关 | 关 | 开 | 关 |
| 1 | 0 | 0 | 关 | 关 | 关 | 开 | 开 | 关 |

**反转（↓）：**（与正转完全镜像）

| 霍尔W | 霍尔V | 霍尔U | U+ | U- | V+ | V- | W+ | W- |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 1 | 0 | 1 | 关 | 开 | 开 | 关 | 关 | 关 |
| 0 | 0 | 1 | 关 | 开 | 关 | 关 | 开 | 关 |
| 0 | 1 | 1 | 关 | 关 | 关 | 开 | 开 | 关 |
| 0 | 1 | 0 | 开 | 关 | 关 | 开 | 关 | 关 |
| 1 | 1 | 0 | 开 | 关 | 关 | 关 | 关 | 开 |
| 1 | 0 | 0 | 关 | 关 | 开 | 关 | 关 | 开 |

**规律总结：**
- 6 个有效状态（缺 000 和 111）
- 状态按**格雷码**变化（相邻状态只有 1 bit 变化）
- 同一时刻始终 2 个 MOS 导通（一上一下），第三相悬空
- 正转上桥顺序：U → U → V → V → W → W（循环）；下桥：V → W → W → U → U → V（循环）

## 五、移植到新电机的完整流程（小白版）

### 第 1 步：测量新电机参数

需要准备：万用表、直流电源、示波器（可选）。

**需要测的数据：**

| 参数 | 测量方法 |
|:----|:---------|
| **相电阻 Rs** | 万用表电阻档，测任意两相线圈之间的阻值，除以 2 |
| **相电感 L** | 用电感表测任意两相线圈之间的电感，除以 2 |
| **极对数 Pn** | 用手转动电机轴一整圈，数一下手感有几下"咯噔"（齿槽转矩），除以 2 |
| **磁链 flux** | 用另一个电机拖动被测电机旋转，示波器看反电动势波形计算（也可以用估算法：铭牌反电动势系数 Ke ÷ √3 ÷ 1000） |

> **小白估算方法：** 如果拿不到精确参数，可以用同类电机参数近似拟合。磁链偏差 20% 以内 FOC 都能工作，只是效率不是最优。

### 第 2 步：修改电机参数文件

打开 `Matlab/FOC_Model.c`，找到 `motor_type motor = { ... }`，改成你的新电机的参数：

```c
motor_type motor = {
    L    = 0.00535F,    // ← 改成你的相电感 (H)
    Pn   = 2.0F,        // ← 改成你的极对数
    Rs   = 6.97F,       // ← 改成你的相电阻 (Ω)
    flux = 0.016884F    // ← 改成你的永磁磁链 (Wb)
};
```

### 第 3 步：校准霍尔安装角

如果使用有感模式，需要校准 `PHASE_SHIFT_ANGLE`：

**方法：对齐法**
1. 电机不通电，用手转动电机
2. 用示波器同时看 U 相反电动势波形和霍尔 U 的信号
3. 测量反电动势过零点到霍尔上升沿的时间差
4. 转换成电角度：`角度 = 时间差 / 电周期 × 360°`
5. 这个角度就是 `PHASE_SHIFT_ANGLE`

如果懒得测，保留 218° 作为初始值，用手转动电机看 HALL_Handle.HallState 是否正确跳变即可。

### 第 4 步：调整电流环 PI 参数

公式法计算初始 PI 值（选保守带宽 ωc=200 rad/s）：

```
CurrKp = L × ωc = 0.00535 × 200 ≈ 1.07
CurrKi = Rs × ωc = 6.97 × 200 ≈ 1394
```

> **注意**：上面是**理论计算初值**。当前代码实际用的是 **CurrKp=0.017, CurrKi=35.0**（FOC_Model.c 中 rt_Simulink_Struct 里的值）——差异约 60 倍是因为模型内部有归一化缩放（电流基准、PWM 占空比标幺化），理论公式算出的值只是数量级参考。**移植新电机时优先用当前值做微调，不要直接套用理论值。**

在 `FOC_Model.c` 中找到 `rt_Simulink_Struct`：

```c
rt_Simulink_Struct.CurrKp = 1.07F;     // ← 根据新电机重新算
rt_Simulink_Struct.CurrKi = 1394.0F;   // ← 根据新电机重新算
```

如果电机运行时电流有高频振荡，减小 CurrKp；如果电流响应太慢，增大 CurrKp。

### 第 5 步：调整速度环 PI 参数

速度环带宽比电流环低 10 倍左右（ωc = 20 rad/s）：

```
spd_kp = 0.003389 (可以先不动，运行时看响应再调)
spd_ki = 0.000144 (可以先不动)
```

速度环调参口诀：

| 现象 | 调法 |
|:----|:----|
| 转速来回震荡 | 减小 spd_kp |
| 转速爬升太慢 | 增大 spd_kp |
| 稳态有静差（到不了目标转速） | 增大 spd_ki |
| 超调严重（超过了又掉回来） | 减小 spd_ki |

### 第 6 步：修改接线（如果需要）

**确认电源：** 新电机额定电压是多少？如果和原来不同（原来是 24V），需要调整电源电压和逆变桥 MOS 管的耐压。

**确认相序：** 如果新电机的 U/V/W 接线顺序和原来不同，在 `hall_FOC_mode()` 中调整 `TIM1->CCR1/2/3` 的映射顺序。

**确认霍尔接线：** 如果新电机的霍尔线顺序和原来不同，需要调整 `Hall_driev.c` 中 PB6/PB7/PB8 对应 W/V/U 的映射。

### 第 7 步：编译下载测试

**初始测试（VF 开环）：**

把 `Hal_State` 设为 1（有感模式），上电后电机应该会先定位、开环拖动，约 3.6 秒后进入闭环运行。如果电机不转或抖动：

| 现象 | 排查 |
|:----|:-----|
| 完全没动静 | 检查母线电压、PWM 是否输出、ADC 采样是否正常 |
| 抖动但不转 | 相序可能错了，交换两相试试 |
| 转一下然后停 | PI 参数不合适，降低 CurrKp |
| 能转但声音大 | PWM 频率不合适，或死区时间不合适 |

**无感测试：**

把 `Hal_State` 设为 0，FOC_Model 会自动使用磁链观测器估算角度。启动流程和有感一样。如果无感模式下抖动或失步：

| 现象dd | 排查 |
|:----|:-----|
| 无感模式启动失败 | 磁链或 Rs/L 参数不准，重新测量电机参数 |
| 高速失步 | PLL 参数不合适，减小 PLLKi |
| 低速抖动 | 加大 LPF 系数，或降低速度环带宽 |

### 第 8 步：通信调试

**串口测试：** 用 VOFA+ 或串口调试助手发送 `AA 55 02 xx xx xx xx 55 AA`（xx 为 float 小端格式的目标转速），看电机是否响应。

**CAN 测试：** 用 CAN 调试工具发送标准帧 ID=0x125，数据 `01 01 00 64 xx xx xx xx`（转速 100RPM），看电机是否响应。

## 六、常见问题排查

### Q1：电机不转

1. 检查电源指示灯是否亮
2. 检查 TIM1 的 MOE 位是否置位（BDTR 寄存器的 bit 15）
3. 测量 6 路 PWM 输出是否有波形
4. 检查 ADC 回调函数是否执行（在 hall_FOC_mode 的入口加 LED 翻转）
5. 检查 FOC_Model 状态，串口读 `state` 值（1=IDLE, 5=Run）

### Q2：电机抖动

1. 如果是有感模式，检查霍尔接线是否稳定，PHASE_SHIFT_ANGLE 是否准确
2. 如果是无感模式，检查磁链参数是否准确，磁链偏差过大会导致角度估算错误
3. 电流环 PI 参数过大也会导致抖动，降低 CurrKp 试试
4. 母线电压采样不准也会导致 SVPWM 计算错误

### Q3：串口收不到数据

1. 检查串口 RX DMA 是否配了（CubeMX USART3 DMA Settings 需要有 USART3_RX）
2. 检查 `USART3_IRQHandler` 中 `UART3_RxHandler` 是否在 `HAL_UART_IRQHandler` 之前调用

### Q4：速度环无法闭环

**当前 FOC_Model 方案：** 模型内部状态机自动管理启动和闭环切换，正常情况下不会出现速度环无法闭环的问题。

如果出现速度环异常，检查以下可能原因：

1. **FOC_Model 状态机未进入 RunStage** — 串口读 `state` 值，如果不是 5 说明还没进闭环，等 3.6 秒启动完成
2. **SpeedRef 被意外覆盖** — 检查串口/CAN/电位器是否在写 `rtU.SpeedRef`
3. **电机参数不准** — Rs/L/flux 与实物偏差太大会导致观测器角度误差，间接影响速度环
4. **FluxWe 输出异常** — 磁链观测器参数（Gamma/LPFFilter）不合适导致速度反馈震荡

> **历史经验（已不再适用）：** 早期手写 VF→FOC 切换方案中，切环瞬间 SpeedRef 和 SpeedFd 相差太大会导致 PI 饱和无法闭环。当时的修复是零误差启动 + 速度斜坡 + 清积分器。FOC_Model 内部状态机已解决了这个问题。

## 七、调试过程记录（踩坑实录）

> 这部分是项目最有价值的调试经验，也是面试重点素材。每个问题都按"现象 → 排查 → 根因 → 解决 → 教训"记录。

### 7.1 电机不转

**现象：** 上电后电机完全没有动静，PWM 输出、电流采样都正常配置了。

**排查步骤：**
1. 检查电源指示灯 → 正常
2. 检查 TIM1 的 MOE 位（BDTR 寄存器 bit15）→ **发现没置位！**

**根因：** TIM1 是高级定时器，输出 PWM 前必须设置主输出使能位 MOE。否则即使 CCR 有值，PWM 也不会输出到引脚。

```c
// 修复：使能 TIM1 主输出
TIM1->BDTR |= TIM_BDTR_MOE;    // 或 HAL 库：HAL_TIM_PWM_Start 内部处理
```

**教训：** STM32 高级定时器（TIM1/TIM8）和普通定时器不同，必须显式开启 MOE 才有输出。这是"高级定时器专坑"。

### 7.2 电机抖动但不转

**现象：** 上电后电机咔哒咔哒抖动，但转不起来。

**排查步骤：**
1. 串口读状态机 state → 一直停在 OpenStage/ThetaAlign，进不了 RunStage
2. 怀疑相序问题 → 交换两相（U/V）→ 抖动消失，能转了

**根因：** 三相接线相序与代码预期不一致，导致磁场方向错误，电机无法被拖动。

**解决：** 交换任意两相（如 U↔V），重新测试。

**教训：** 电机抖动不转，**第一优先怀疑相序**，其次才是 PI 参数。相序错误是物理层面的问题，调参解决不了。

### 7.3 电机啸叫 / 发烫

**现象：** 电机高速运行时发出尖锐啸叫，外壳烫手（>80°C）。

**排查：**
1. 啸叫 = PWM 频率落在人耳可听范围（20Hz~20kHz），本机 10kHz PWM 正好在范围内
2. 发烫 = 电流过大，可能是死区时间不足导致上下桥直通（短路电流）

**解决：**
- 啸叫：确认死区时间足够（120 ticks ≈ 0.7μs），可尝试提高 PWM 频率避开听觉范围（需权衡开关损耗）
- 发烫：检查死区 + 电流采样是否正常（偏置/增益错会导致电流误判 → 输出错误占空比）

**教训：** 电机发烫先查死区，啸叫是 PWM 频率与听觉范围的问题，两者常同时出现。

### 7.4 无感启动失败

**现象：** 切换到无感模式（Hal_State=0）后，电机无法启动或启动即失步。

**排查过程（关键）：**
1. 确认电机参数（Rs/L/flux）准确 → 重新测量
2. 观察磁链观测器输出角度（FluxTheta）→ 发现角度估算混乱
3. 检查观测器参数 → Gamma/LPFFilter 不合适
4. **关键发现：** 启动时观测器角度还没收敛，直接切闭环必然失步

**根因：** 无感启动是一个**先开环后闭环**的过程。电机静止时反电动势为 0，观测器无法工作，必须先 VF 开环拖动到一定转速，等观测器收敛后才能切闭环。

**解决：** FOC_Model 内部状态机已经处理了这个过程（OpenStage 开环拖动 → ThetaAlign 角度对齐 → RunStage 闭环）。如果启动失败：
- 检查 Rs/L/flux 是否与实物偏差过大（**这是无感失败的头号原因**）
- 减小 PLLKi（PLL 太激进会导致角度跟踪振荡）
- 加大 LPFFilter（观测器噪声大时）

**教训：** 无感 FOC 的关键不是闭环算法，而是**启动过程**（开环→收敛→切换）。参数不准时无感一定失败，有感还能靠霍尔兜底。

### 7.5 速度环调参（振荡 → 稳定）

**现象：** 速度环闭环后转速来回振荡，无法稳定在目标值。

**调参过程（口诀：先 P 后 I，先小后大）：**
1. **先把 spd_ki 设为 0**，只留 spd_kp → 观察响应
2. 从小到大调 spd_kp：太小爬升慢，太大振荡
3. 找到临界振荡点后，**回调到临界值的 60~70%**（工程惯例）
4. 再加 spd_ki 消除静差：从小到大，出现超调就回调

```
现象          → 调法
转速振荡      → 减小 spd_kp
爬升太慢      → 增大 spd_kp
稳态有静差    → 增大 spd_ki
超调严重      → 减小 spd_ki
```

**当前值：** spd_kp=0.003389, spd_ki=0.000144（已经调稳）

**教训：** 调 PI 的黄金法则——**先 P 后 I，P 调稳了再上 I**。直接两个一起调，分不清是哪个的问题。

### 7.6 霍尔信号问题（5 项修复的逐步发现过程）

**背景：** 有感模式刚跑起来时，速度环能闭环，但转速不稳，偶尔跳变。

**第 1 个发现（bValidTransition）：**
- 现象：霍尔速度偶尔出现巨大跳变（几百→几千 RPM 瞬间跳）
- 排查：抓串口波形，发现速度跳变总是伴随**异常的霍尔状态跳转**
- 根因：电机运行中霍尔信号受噪声干扰，产生**非法跳变**（如 5→5 或 6→1 这种非相邻状态），导致速度计算错误
- 解决：每个霍尔 case 里判断"上一个状态是否合法"，非法跳变不更新角度和速度（`bValidTransition` 标志）

**第 2 个发现（变量初始化）：**
- 现象：上电首次运行速度异常
- 根因：复位后全局变量初始值不确定（RAM 随机值），速度环初始状态不可预测
- 解决：`HALL_Init_Electrical_Angle` 里显式初始化所有变量（AvrElSpeedDpp=0, HallSpeed=0, Direction=POSITIVE）

**第 3 个发现（switch 后统一判断）：**
- 现象：偶尔角度跳变
- 根因：switch 里每个 case 的合法/非法判断不统一，有的分支漏了
- 解决：每个 case 都设置 bValidTransition，switch 结束后统一判断 `if (!bValidTransition) return`

**第 4 个发现（先保存 bHallUpdated）：**
- 现象：霍尔速度更新滞后，速度环响应慢
- 根因：`hall_FOC_mode` 里先清了 bHallUpdated，导致速度反馈读不到最新霍尔数据
- 解决：先保存快照，再清标志，后续判断用快照

**教训：** 霍尔信号的坑是**逐个出现的**——先解决噪声触发，再解决初始化，再解决逻辑统一，最后解决数据同步。每个问题都要从"现象 → 数据 → 根因"一步步推。

## 九、面试问答（项目亮点与难点）

> 这个项目最大的亮点：**自己搭 Simulink 模型 + 自动生成代码**，把"控制算法设计"和"嵌入式工程"结合。面试时重点讲这个工作流，以及踩坑过程。

### 9.1 项目亮点

| 亮点 | 说明 |
|:----|:-----|
| **Simulink 模型自建** | FOC 算法（电流环/速度环/磁链观测器/PLL/状态机）是自己搭的模型，不是抄现成代码 |
| **代码自动生成** | Simulink Coder 生成嵌入式 C 代码，保证算法与模型一致，快速迭代 |
| **有感无感一体化** | 同一套代码通过 `Hal_State` 切换，霍尔角度 / 磁链观测器角度二选一，硬件复用 |
| **三电阻电流采样** | TIM1_CH4 触发 ADC 注入组同步转换，避开开关噪声，偏移校准消除零漂 |
| **三路调速** | 串口（VOFA+ 协议）/ CAN / 电位器，覆盖调试和现场两种场景 |
| **启动状态机** | IDLE→Align→Open→ThetaAlign→Run 五阶段，解决无感启动难题 |

### 9.2 高频问答

**Q1：FOC 是什么？为什么 BLDC 要用 FOC？**

> FOC（磁场定向控制）把三相电流解耦成 Id（励磁）和 Iq（转矩）两个独立分量，像直流电机一样控制。BLDC 用 FOC 可以得到**平稳的转矩**（相比方波换相的 6 次/圈转矩脉动，FOC 是连续的），噪音小、效率高。代价是算法复杂，需要精确的转子角度。

**Q2：为什么要有感 / 无感两种模式？**

> 有感用霍尔传感器，低速性能好、启动可靠，但霍尔会坏、增加成本；无感用磁链观测器，省掉霍尔，但低速时反电动势太小，观测器无法工作，启动困难。**工业上两者互补**：要求高的场合用有感，降低成本用无感。

**Q3：无感 FOC 怎么启动？**

> 三步：先 AlignStage 给固定角度把转子定位 → OpenStage 开环 VF 拖动（频率斜坡上升），让电机转起来、观测器收敛 → ThetaAlign 把开环角度和观测器角度对齐 → RunStage 切闭环。**关键：低速开环、高速闭环**。

**Q4：电流环和速度环怎么配合？**

> 内环是电流环（10kHz，快），外环是速度环（1kHz，慢）。速度环输出 Iq 参考值给电流环，电流环控制实际电流跟随。内环必须比外环快 10 倍左右，否则内外环互相打架。

**Q5：SVPWM 比 SPWM 好在哪里？**

> SVPWM 通过零序分量注入（马鞍波），把母线电压利用率从 78.5% 提高到 ~91%（约提升 15%），同样的母线电压能跑更高的转速/输出更大转矩。

**Q6：Simulink 自动生成的代码能直接用吗？**

> 能，但要注意：① 模型里配置的定时器/中断要和硬件一致；② 生成代码要手动写"硬件接口层"（ADC 读电流、写 PWM 占空比）；③ 模型和代码要版本对应，改模型必须重新生成。我的做法是：**算法放模型里自动生成，外设操作手写封装**，两边通过全局结构体（rtU/rtY）对接。

**Q7：霍尔角度和 FOC 的角度怎么同步？**

> 霍尔每 60° 才更新一次，中间用速度插值（AvrElSpeedDpp 每 100μs 累加），在两个边沿之间得到连续角度。还要用 DeltaAngle 做补偿（霍尔实测角度 - 累加角度 的差除以采样次数），消除霍尔测量误差的累积。

**Q8：电流采样为什么要用注入组？**

> 三相电流采样必须和 PWM 同步——在 PWM 周期中点（下桥导通、电流稳定时）采样，避开开关噪声。TIM1_CH4 的 OC4REF 触发 ADC 注入组转换，正好对齐 PWM 中点。

**Q9：速度环闭环的关键是什么？（重点，有踩坑）**

> 早期手写 VF→FOC 切换时，切闭环瞬间 SpeedRef 和实际转速相差太大会导致 PI 饱和、永远无法闭环。解决：**零误差启动**（切换时 SpeedRef=实际转速）+ **速度斜坡** + **清积分器**。后来改用 FOC_Model 内部状态机，模型自动处理了角度同步和速度过渡，这个问题就不用手动维护了。**面试讲这个能体现你真正调过速度环。**
