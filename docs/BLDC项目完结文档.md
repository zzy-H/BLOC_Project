# BLDC 项目完结文档

> STM32G431 + FD6288T 驱动板 — 有感/无感 FOC 驱动器

---

## 一、项目概述

本项目基于 STM32G431CBT6 微控制器，配合 FD6288T 三相栅极驱动芯片，实现了一台无刷直流电机（BLDC）的磁场定向控制（FOC）驱动器。项目使用 Simulink 自动生成的 FOC 算法代码，支持有霍尔传感器和无传感器两种控制模式，支持串口、CAN、电位器三种调速方式。

### 硬件架构

```
24V DC ──┬──→ SCT2A10STER ──→ 12V ──→ SCT2230TVBR ──→ 5V ──→ AMS1117 ──→ 3.3V
          └──→ 三相逆变桥 (BSC0702LS × 6) ──→ 电机三相绕组
                      ↑
              FD6288T 栅极驱动
                      ↑
              STM32G431 输出 6 路互补 PWM
```

### 软件架构

```
ADC 中断 (10kHz) ──→ 读电流 → FOC_Model_step() → 写 CCR
       ↑                         ↑
TIM1_CH4 触发               FOC_Model 内部
                            ├─ 状态机 (IDLE→Align→Open→Theta→Run)
                            ├─ 电流环 (10kHz)
                            ├─ 速度环 (1kHz)  
                            ├─ 磁链观测器 + PLL (无感用)
                            └─ SVPWM 输出

TIM4 中断 (霍尔边沿) ──→ 更新角度和速度

main 循环 ──→ FDCAN_Control() → CAN 调速
           → USART3_Anylze() → 串口调参
           → send_UVWV() → VOFA 数据上报
```

## 二、项目功能介绍

### 2.1 有感 FOC 控制（霍尔传感器）

**原理：** 三个霍尔传感器（120° 间隔）安装在电机内部，检测转子磁极位置。每当转子转过 60° 电角度，三个霍尔的电平组合变化一次，共 6 种有效状态（格雷码编码）。

**霍尔信号采集：** TIM4 配置为霍尔传感器模式，三路霍尔信号（PB6/PB7/PB8）的任意一路电平跳变都会触发 TIM4 输入捕获中断。在中断服务函数中读取捕获值并更新转子角度和转速。

**关键函数：**

| 函数 | 位置 | 作用 |
|:----|:----|:-----|
| `HALL_Init_Electrical_Angle()` | Hall_driev.c | 上电时读取初始霍尔状态，确定转子所在扇区 |
| `HALL_Get_Electrical_Angle()` | Hall_driev.c | 霍尔边沿触发时调用，解码状态跳变、计算电角度基准、计算速度 |
| `HAL_TIM_IC_CaptureCallback()` | stm32g4xx_it.c | TIM4 输入捕获中断回调，调用 HALL_Get_Electrical_Angle |

**角度插值：** 霍尔传感器每 60° 电角度才更新一次位置。为了获得连续平滑的角度，在 ADC 回调中（每 100μs）用 `AvrElSpeedDpp`（每步的电角度增量）累加角度，在两个霍尔边沿之间做线性插值。

**5 项霍尔信号修复（调试经验）：**

| 修复 | 解决什么问题 |
|:----|:------------|
| `bValidTransition` 标志 | 霍尔噪声导致的虚假触发会计算出巨大速度，跳过无效跳变 |
| 初始化所有变量 | 复位后 RAM 值不确定，导致速度环初始状态异常 |
| 每个 case 设置 bValidTransition | 只对有效霍尔跳变计算速度和角度 |
| switch 后跳过无效跳变 | 防止无效跳变污染速度 LPF 滤波结果 |
| 先保存 bHallUpdated 再清零 | 保证角度同步和速度反馈都能读到正确的霍尔数据 |

### 2.2 无感 FOC 控制（磁链观测器 + PLL）

**原理：** 电机旋转时，转子永磁体在定子绕组中产生反电动势（Back-EMF）。反电动势的相位包含转子位置信息。通过观测反电动势，就能估算出转子角度，无需霍尔传感器。

**FOC_Model 中的磁链观测器结构：**

```
FluxObserver (磁链观测器) → LPF (低通滤波) → PLL (锁相环) → FluxTheta (估算角度)
                                                             → FluxWe (估算速度)
```

| 模块 | Simulink 路径 | 作用 |
|:----|:-------------|:-----|
| FluxObserver | `<S16>` | 根据电流和电压估算定子磁链 |
| LPF | `<S17>` | 低通滤波，滤除观测器噪声 |
| PLL | `<S18>` | 锁相环跟踪磁链角度，输出平滑的 θ 和 ω |

**有/无感切换：** 通过全局变量 `Hal_State` 控制：

```c
if (Hal_State == 0)     // 无感模式
    theta = FluxTheta;   // 使用磁链观测器估算角度
else                     // 有感模式
    theta = HALL_Handle.MeasuredElAngle;  // 使用霍尔传感器角度
```

**启动流程（FOC_Model 内置状态机）：**

| 状态 | 持续时间 | 行为 |
|:----|:--------:|:-----|
| IDLE (state=1) | — | 等待 `Motor_OnOff=1` |
| AlignStage (state=2) | 100ms | 固定角度注入 Iq，将转子拉到已知位置 |
| OpenStage (state=3) | 3s | 开环拖动，频率从 0 开始斜坡上升 |
| ThetaAlign (state=4) | 500ms | 观测器角度和开环角度对齐过渡 |
| RunStage (state=5) | — | 闭环运行，速度和电流双环控制 |

### 2.3 FOC 算法（Simulink 自动生成）

**FOC 控制链路：**

```
ia, ib, ic (三相电流)
    ↓
Clark 变换 → Iα, Iβ (两相静止坐标系)
    ↓
Park 变换 → Id, Iq (两相旋转坐标系)，需要 θ 角
    ↓
Id PI 控制器 → Ud        Iq PI 控制器 → Uq
    ↓
逆 Park 变换 → Uα, Uβ (需要 θ 角)
    ↓
SVPWM → tABC (三相占空比) → TIM1->CCR1/2/3
```

**电流环（内环）：** 运行频率 10kHz。控制 Id=0（不产生励磁），控制 Iq 产生扭矩。PI 参数：

```
CurrKp = 0.017    CurrKi = 35.0
```

**速度环（外环）：** 运行频率 1kHz（每 10 次电流环执行一次）。PI 输出作为 Iq 参考值输入电流环：

```
spd_kp = 0.003389    spd_ki = 0.000144
```

**SVPWM（空间矢量调制）：** 将 Uα, Uβ 合成为三相马鞍波，相比正弦波调制，母线电压利用率提高约 15%。

### 2.4 PWM 生成

**TIM1 配置：**

| 参数 | 值 |
|:----|:---:|
| 预分频 | 0 (170MHz) |
| 计数模式 | 中央对齐 (Center-aligned) |
| ARR | 8500 |
| 死区时间 | 120 个时钟周期 (~0.7μs) |
| PWM 频率 | 170MHz ÷ (2 × 8500) ≈ 10kHz |

**引脚映射：**

| TIM1 通道 | GPIO | 驱动板 | 相序 |
|:---------|:----|:-------|:----:|
| CH1 + CH1N | PA8 + PB13 | HIN3 + LIN3 | W 相 |
| CH2 + CH2N | PA9 + PB14 | HIN2 + LIN2 | V 相 |
| CH3 + CH3N | PA10 + PB15 | HIN1 + LIN1 | U 相 |
| CH4 | PA? | ADC 触发 | — |

FOC 算法计算出的 tABC 值写入 TIM1->CCR1/2/3，硬件自动比较计数器值，输出对应占空比的 PWM 波形。

### 2.5 电流采样

**三电阻采样方案：** 三个采样电阻（各 5mΩ）串联在三相下桥 MOS 管的源极和 GND 之间，通过 STM32G431 内置运放（OPAMP）放大后由 ADC 采集。

**运放增益：** 7.33 倍（11kΩ ÷ 1.5kΩ），1.65V 共模偏置。

**触发方式：** TIM1_CH4 的 OC4REF 信号触发 ADC1 和 ADC2 的注入组同步转换（与 PWM 同步，避开开关噪声）。

**ADC 通道：**

| ADC | 通道 | 引脚 | 信号 | 寄存器 |
|:---|:----|:----|:----|:------|
| ADC1 | IN3 | PA2 | U 相电流 | JDR1 |
| ADC1 | IN12 | PB1 | V 相电流 | JDR2 |
| ADC1 | IN1 | PA0 | 母线电压 | JDR3 |
| ADC2 | IN3 | PA6 | W 相电流 | JDR1 |

**偏移校准：** 上电后前 10 次采样不做控制，只采样并累加零漂值。之后每次采样减去零漂，得到真实电流值。

### 2.6 速度闭环

**速度环在 FOC_Model 内部自动运行（1kHz），不需要手动干预。**

**速度环链路：**

```
SpeedRef（外部输入：串口/CAN/电位器）
    ↓
误差 = SpeedRef - FluxWe（磁链观测器 PLL 输出的估算速度）
    ↓
速度环 PI（spd_kp=0.003389, spd_ki=0.000144）
    ↓
输出限幅 → 作为 Iq 参考 → 电流环
```

**速度反馈来源：** 无论有感还是无感模式，速度反馈始终来自 `FluxWe`。有感时霍尔角度只覆盖模型内部的 theta 角度用于 Park/反 Park 变换，不影响速度反馈。

**启动过程由 FOC_Model 内部状态机自动管理：**

| 阶段 | 时长 | 行为 |
|:----|:----:|:-----|
| AlignStage | 100ms | 固定角度注入 Iq，转子定位 |
| OpenStage | 3s | VF 开环拖动，内部自动做频率斜坡和角度积分 |
| ThetaAlign | 500ms | 开环角度和估算角度对齐，保证切到闭环时角度连续 |
| RunStage | — | 闭环运行，速度环和电流环正常工作 |

模型内部在 ThetaAlign 阶段已经做了角度同步和速度缓冲，切到 RunStage 时不会出现速度跳变。**不需要手动做零误差启动、速度斜坡或清积分器。**

> **历史背景：** 早期手动 VF→FOC 切换方案中，切闭环瞬间 SpeedRef 和实际转速相差太大会导致 PI 饱和无法闭环。当时的修复方案是零误差启动 + 速度斜坡 + 清积分器。切换到 FOC_Model 后该问题由模型内部自动处理，不再需要手动维护。

### 2.7 VF 开环控制（备用启动方式）

VF 模式不依赖任何位置反馈，直接给电机施加旋转电压，电机被电压产生的旋转磁场拖动着转。用于电机参数测试和低转速启动场景。

```c
VF_rtU.ud   = 0.0f;       // 直轴电压
VF_rtU.uq   = 12.0f;      // 交轴电压（产生扭矩）
VF_rtU.Freq = 4.0f;       // 电频率 4Hz
```

### 2.8 串口上位机通信

**协议格式（VOFA+ JustFloat 协议）：**

```
帧头 0xAA 0x55 | 指令码 | 4 字节数据 (float, 小端) | 帧尾 0x55 0xAA
```

**支持的命令：**

| 指令码 | 功能 | 数据 |
|:-----:|:----|:----|
| 0x01 | 电机启停 | 无 |
| 0x02 | 速度设定 | float RPM |
| 0x03 | 速度环 Kp | float |
| 0x04 | 速度环 Ki | float |
| 0x05 | 电流环 Kp | float |
| 0x06 | 电流环 Ki | float |
| 0x0C | 有感/无感切换 | float: 0=无感 1=有感 |

**实现要点：**
- 使用 DMA + IDLE 中断实现不定长帧接收
- RX DMA 工作在 Circular 模式，帧尾空闲时触发中断
- 每次解析完重新启动 DMA 接收

### 2.9 CAN 上位机调速

**帧格式（标准帧，ID=0x125，8 字节）：**

| 字节 | 含义 |
|:---:|:----|
| [0] | 0x01=启动，其他=停止 |
| [1] | 0x01=正转，其他=反转 |
| [2] | 速度高 8 位 |
| [3] | 速度低 8 位 |

**关键函数：** `FDCAN_Control()` 在 `mycan.c` 中，在 main 循环中轮询调用。检查到新帧后解析数据，更新 `rtU.SpeedRef` 和 `rtU.Motor_OnOff`。

**配置：**
- 经典 CAN 模式，128kbps
- 滤波器设为范围过滤，接收 ID 0x000~0x1FF
- 接收 FIFO 中断触发，置位新帧标志后由主循环处理

### 2.10 电位器调速

电位器接 PB12（ADC1_IN11），10 次采样取平均值消除抖动，映射到 600~2300 RPM 的范围。

```c
if (电位器电压 > 1.65V)
    SpeedRef = (电压差值 × 0.83) + 600    // 正转
else
    SpeedRef = -((1.65V - 电压) × 0.83 + 600)  // 反转
```

## 三、关键算法解析

### 3.1 Clark 变换

将三相电流 ia, ib, ic 变换到两相静止坐标系 Iα, Iβ：

```
Iα = 2/3 × ia - 1/3 × (ib + ic)
Iβ = (ib - ic) / √3
```

由于 ia + ib + ic = 0（星形连接，无中性线），可简化为：

```
Iα = ia
Iβ = (ib - ic) / √3
```

### 3.2 Park 变换

将两相静止坐标系 Iα, Iβ 变换到两相旋转坐标系 Id, Iq（随转子同步旋转）：

```
Id  =  Iα × cosθ + Iβ × sinθ
Iq  = -Iα × sinθ + Iβ × cosθ
```

- Id 是励磁分量（产生磁场），控制目标为 0
- Iq 是转矩分量（产生力矩），由速度环输出决定

### 3.3 逆 Park 变换

将 Ud, Uq 变换回 Uα, Uβ：

```
Uα = Ud × cosθ - Uq × sinθ
Uβ = Ud × sinθ + Uq × cosθ
```

### 3.4 SVPWM（空间矢量调制）

将 Uα, Uβ 合成为三相马鞍波，比 SPWM 母线电压利用率高约 15%。

```
1. 逆 Clark：Ua = Uα, Ub = -0.5×Uα+√3/2×Uβ, Uc = -0.5×Uα-√3/2×Uβ
2. 零序注入：V0 = -0.5×(Umax + Umin)
3. 调制：tABC = (-(Ux + V0) / Vbus + 0.5) × 8500
```

### 3.5 磁链观测器（无感核心）

根据电机电压方程，从静止坐标系下的电压和电流估算定子磁链：

```
ψα = ∫(uα - Rs × iα) dt
ψβ = ∫(uβ - Rs × iβ) dt
```

从磁链中提取反电动势：

```
eα = dψα/dt - L × diα/dt
eβ = dψβ/dt - L × diβ/dt
```

### 3.6 PLL（锁相环）

从估算的反电动势中提取角度和速度。PLL 相比直接 atan2 计算的优势：输出平滑、抗噪声、天然带滤波。

```
误差 = êα × cosθ̂ + êβ × sinθ̂ (当 θ̂ 接近 θ 时，误差 ≈ θ - θ̂)
↓
PI 控制器 → ω̂ (估算速度)
↓
积分器 → θ̂ (估算角度)
```

### 3.7 霍尔传感器驱动

```c
// 霍尔状态解码（正转：1→5→4→6→2→3→1）
switch (HallState) {
    case 5:  // 101: 正转从 1 来，反转从 4 来
    case 4:  // 100: 正转从 5 来，反转从 6 来
    case 6:  // 110: 正转从 4 来，反转从 2 来
    case 2:  // 010: 正转从 6 来，反转从 3 来
    case 3:  // 011: 正转从 2 来，反转从 1 来
    case 1:  // 001: 正转从 3 来，反转从 5 来
}
```

速度计算：

```
AvrElSpeedDpp = (π/3) / (TIM4 捕获值 / 3.2M × 10000)
TempSpeed = (π/3) / (TIM4 捕获值 / 3.2M) × 30 / (2π)
HallSpeed = LPF(HallSpeed, TempSpeed × Direction, 0.2379)
```

## 五、移植到新电机的完整流程（小白版）

### 第 1 步：测量新电机参数

需要准备：万用表、直流电源、示波器（可选）。

**需要测的数据：**

| 参数 | 测量方法 |
|:----|:---------|
| **相电阻 Rs** | 万用表电阻档，测任意两相线圈之间的阻值，除以 2 |
| **相电感 L** | 用电感表测任意两相线圈之间的电感，除以 2 |
| **极对数 Pn** | 用手转动电机轴一整圈，数一下手感有几下"咯噔"（齿槽转矩），除以 2 |
| **磁链 flux** | 用另一个电机拖动被测电机旋转，示波器看反电动势波形计算（也可以用估算法：铭牌反电动势系数 Ke ÷ √3 ÷ 1000） |

> **小白估算方法：** 如果拿不到精确参数，可以用同类电机参数近似拟合。磁链偏差 20% 以内 FOC 都能工作，只是效率不是最优。

### 第 2 步：修改电机参数文件

打开 `Matlab/FOC_Model.c`，找到 `motor_type motor = { ... }`，改成你的新电机的参数：

```c
motor_type motor = {
    L    = 0.00535F,    // ← 改成你的相电感 (H)
    Pn   = 2.0F,        // ← 改成你的极对数
    Rs   = 6.97F,       // ← 改成你的相电阻 (Ω)
    flux = 0.016884F    // ← 改成你的永磁磁链 (Wb)
};
```

### 第 3 步：校准霍尔安装角

如果使用有感模式，需要校准 `PHASE_SHIFT_ANGLE`：

**方法：对齐法**
1. 电机不通电，用手转动电机
2. 用示波器同时看 U 相反电动势波形和霍尔 U 的信号
3. 测量反电动势过零点到霍尔上升沿的时间差
4. 转换成电角度：`角度 = 时间差 / 电周期 × 360°`
5. 这个角度就是 `PHASE_SHIFT_ANGLE`

如果懒得测，保留 218° 作为初始值，用手转动电机看 HALL_Handle.HallState 是否正确跳变即可。

### 第 4 步：调整电流环 PI 参数

公式法计算初始 PI 值（选保守带宽 ωc=200 rad/s）：

```
CurrKp = L × ωc = 0.00535 × 200 ≈ 1.07
CurrKi = Rs × ωc = 6.97 × 200 ≈ 1394
```

在 `FOC_Model.c` 中找到 `rt_Simulink_Struct`：

```c
rt_Simulink_Struct.CurrKp = 1.07F;     // ← 根据新电机重新算
rt_Simulink_Struct.CurrKi = 1394.0F;   // ← 根据新电机重新算
```

如果电机运行时电流有高频振荡，减小 CurrKp；如果电流响应太慢，增大 CurrKp。

### 第 5 步：调整速度环 PI 参数

速度环带宽比电流环低 10 倍左右（ωc = 20 rad/s）：

```
spd_kp = 0.003389 (可以先不动，运行时看响应再调)
spd_ki = 0.000144 (可以先不动)
```

速度环调参口诀：

| 现象 | 调法 |
|:----|:----|
| 转速来回震荡 | 减小 spd_kp |
| 转速爬升太慢 | 增大 spd_kp |
| 稳态有静差（到不了目标转速） | 增大 spd_ki |
| 超调严重（超过了又掉回来） | 减小 spd_ki |

### 第 6 步：修改接线（如果需要）

**确认电源：** 新电机额定电压是多少？如果和原来不同（原来是 24V），需要调整电源电压和逆变桥 MOS 管的耐压。

**确认相序：** 如果新电机的 U/V/W 接线顺序和原来不同，在 `hall_FOC_mode()` 中调整 `TIM1->CCR1/2/3` 的映射顺序。

**确认霍尔接线：** 如果新电机的霍尔线顺序和原来不同，需要调整 `Hall_driev.c` 中 PB6/PB7/PB8 对应 W/V/U 的映射。

### 第 7 步：编译下载测试

**初始测试（VF 开环）：**

把 `Hal_State` 设为 1（有感模式），上电后电机应该会先定位、开环拖动，约 3.6 秒后进入闭环运行。如果电机不转或抖动：

| 现象 | 排查 |
|:----|:-----|
| 完全没动静 | 检查母线电压、PWM 是否输出、ADC 采样是否正常 |
| 抖动但不转 | 相序可能错了，交换两相试试 |
| 转一下然后停 | PI 参数不合适，降低 CurrKp |
| 能转但声音大 | PWM 频率不合适，或死区时间不合适 |

**无感测试：**

把 `Hal_State` 设为 0，FOC_Model 会自动使用磁链观测器估算角度。启动流程和有感一样。如果无感模式下抖动或失步：

| 现象dd | 排查 |
|:----|:-----|
| 无感模式启动失败 | 磁链或 Rs/L 参数不准，重新测量电机参数 |
| 高速失步 | PLL 参数不合适，减小 PLLKi |
| 低速抖动 | 加大 LPF 系数，或降低速度环带宽 |

### 第 8 步：通信调试

**串口测试：** 用 VOFA+ 或串口调试助手发送 `AA 55 02 xx xx xx xx 55 AA`（xx 为 float 小端格式的目标转速），看电机是否响应。

**CAN 测试：** 用 CAN 调试工具发送标准帧 ID=0x125，数据 `01 01 00 64 xx xx xx xx`（转速 100RPM），看电机是否响应。

## 六、常见问题排查

### Q1：电机不转

1. 检查电源指示灯是否亮
2. 检查 TIM1 的 MOE 位是否置位（BDTR 寄存器的 bit 15）
3. 测量 6 路 PWM 输出是否有波形
4. 检查 ADC 回调函数是否执行（在 hall_FOC_mode 的入口加 LED 翻转）
5. 检查 FOC_Model 状态，串口读 `state` 值（1=IDLE, 5=Run）

### Q2：电机抖动

1. 如果是有感模式，检查霍尔接线是否稳定，PHASE_SHIFT_ANGLE 是否准确
2. 如果是无感模式，检查磁链参数是否准确，磁链偏差过大会导致角度估算错误
3. 电流环 PI 参数过大也会导致抖动，降低 CurrKp 试试
4. 母线电压采样不准也会导致 SVPWM 计算错误

### Q3：串口收不到数据

1. 检查串口 RX DMA 是否配了（CubeMX USART3 DMA Settings 需要有 USART3_RX）
2. 检查 `USART3_IRQHandler` 中 `UART3_RxHandler` 是否在 `HAL_UART_IRQHandler` 之前调用

### Q4：速度环无法闭环

**当前 FOC_Model 方案：** 模型内部状态机自动管理启动和闭环切换，正常情况下不会出现速度环无法闭环的问题。

如果出现速度环异常，检查以下可能原因：

1. **FOC_Model 状态机未进入 RunStage** — 串口读 `state` 值，如果不是 5 说明还没进闭环，等 3.6 秒启动完成
2. **SpeedRef 被意外覆盖** — 检查串口/CAN/电位器是否在写 `rtU.SpeedRef`
3. **电机参数不准** — Rs/L/flux 与实物偏差太大会导致观测器角度误差，间接影响速度环
4. **FluxWe 输出异常** — 磁链观测器参数（Gamma/LPFFilter）不合适导致速度反馈震荡

> **历史经验（已不再适用）：** 早期手写 VF→FOC 切换方案中，切环瞬间 SpeedRef 和 SpeedFd 相差太大会导致 PI 饱和无法闭环。当时的修复是零误差启动 + 速度斜坡 + 清积分器。FOC_Model 内部状态机已解决了这个问题。
